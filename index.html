    ✦ 基础对话
    
      
    发送消息
    桌面端 Enter 直接发送；手机端点按钮发送，Enter 换行
    
      
    换行
    Shift + Enter 在输入框内插入换行（桌面端）
    
      
    停止生成
    生成中点输入框右侧红色 ■ 停止 按钮，立即中断全部请求，已生成内容保留
    
      
    新建对话
    侧边栏 → 新建对话；Header 右上角（模型设置右边、对话设置左边）也有一个 💬+ 快捷按钮，随手开新窗
    
      
    搜索对话
    侧边栏顶部搜索框实时过滤，支持对话标题关键词
    
      
    页内查找
    Ctrl + F 唤出页内查找条，在当前页面里搜任意文字：Enter 下一个、Shift+Enter 上一个、Esc 关闭。所有命中会一起高亮，当前那处是橙色。exe 里也能用——桌面窗口本来没有浏览器那条查找栏，这是自己做的
    
      
    重命名
    鼠标悬浮对话列表项 → 点击 ✎ 图标；或对话发出后自动截取前 22 字命名
    
      
    置顶对话
    悬浮 → 点击图钉图标置顶，置顶对话排在列表最前面
    
      
    手机上的对话操作
    手机上长按对话条目，会显示置顶 / 改名 / 删除
    
      
    对话排序
    列表按最后一次说话的时间排，最新的在最上面；标题旁的小字写「几分钟前 / 昨天 / 具体日期」
    
      
    批量删除对话
    侧边栏搜索框右侧的勾选图标 → 进入勾选模式，多选对话后点底部托盘删除（移入回收站，可恢复）。桌面端也可以直接 Ctrl + 左键 点对话进多选
    
      
    删掉就不会再回来
    删对话时会记一个「墓碑」，云端同步再也不会把它拉回来——以前批量删掉的对话会在下次启动时全部复活，就是因为少了这个。删除失败（没网、token 过期）也不要紧，下次同步会自动补删，直到云端确认干净为止。从回收站恢复出来的对话会拿到一个新编号，不受旧墓碑影响
    
      
    复制快捷键
    输入框底部有 📋 复制我的消息 / 📋 复制上条回复 按钮，一键拷贝
    
      
    🪟 无缝换窗
    小组件 → 无缝换窗：一个对话聊长了想换新的，又不想从零开始时用。按轮勾选（一轮 = 你的一条消息 + 它后面所有回复），选好点「🪟 搬到新对话」，选中的原样复制进一个新对话。原对话一个字都不动，挑错了重来一次就行。
    跳过的地方会自动写明「隔了 4 天，省略了 62 条」，模型才知道这不是连续的（不写的话它会把三天前和刚才当成一口气说完的）。有「最近 3 轮 / 最近 10 轮 / 全选」快捷键和实时的 token 估算（选中大约多少、占原来百分之几）；勾中的那一轮还能补一句情绪备注（一个词就够：心疼 / 在气头上）。图片默认不带，可以勾「带上图片」

    思考链翻成中文
    英文的思考链会被电脑上的本地小模型（Ollama 里的 qwen3.5-9b-q3，你叫它「翻译官」的那个）翻成中文，回复写完后自动翻，默认显示中文。思考块上的小钮在 中 / EN 之间切，这只管这台设备想看哪种。原文一个字不动，回填给模型的永远是英文原文，译文只给你看。
    旧消息，或者当时电脑没开的那些，思考块上挂着一个 译，点了才翻：变成「译…」是在翻，变成 ✕ 是没翻成（鼠标停上去写着是连不上电脑上的翻译，还是没翻出来）。本来就是中文想的（汉字占三成以上）不给「译」。英文思考里夹着的中文段原样留着，只翻英文那几段，不会被改写成另一种说法。碰上敏感内容，Qwen 偶尔会拒翻，认出来会换一个去过拒答的底子重翻那一段；以前存下的拒绝也不会当成译文显示。
    ⚠️ 前提是电脑上 Ollama 开着、server.js 在跑。翻不了时什么提示都没有，思考照旧显示英文——「思考一直是英文」先看 Ollama 还在不在。手机要连得上电脑

    图片自动瘦身
    发给 AI 的图片会自动缩到长边 768px 再发（拍照、粘贴、拖拽、选文件、视频抽帧都一样）。一张 1900×900 的截图原本值约 2280 token，缩完只剩 373，而且图片会留在对话历史里每轮重发——不缩的话聊 50 轮就是十几万 token 花在同一张图上。768 是模型看图的上限，再大也不会看得更清楚，只是多收钱
    
      
    看过的图会记住
    一张图第一次发出去时，电脑上的 server.js 会另叫 Haiku 5.5 写一段客观描述（走订阅额度，一张图不到 1k token），挂在那张图身上，跟着对话一起同步。之后这张图在历史里就换成「[图片：描述]」文字：
    订阅 Claude、订阅 GPT：这两条通道从来只收最后一条消息的图，以前历史里的图一转头就忘，连「这里有过一张图」都不知道——现在历史图全换成描述，它记得。API、Gemini：最近 3 条消息里的图照发原图（你多半还在问「左下角那个是什么」），更早的换成文字，不再每轮整张重发。
    换不换只看「隔了几条消息」和「有没有描述」，不随时间变，所以每张图一辈子只换一次，之后每轮逐字节相同，不打穿缓存。刚发的图绝不等描述，这一轮照发原图；同一张图再发一次也照发原图，只是不用再描述一遍。视频抽帧不描述。手机连不上电脑时写不了描述，那几张就照旧
    
      
    省 token（提示词缓存）
    系统提示被切成「稳定段 + 易变段」，稳定的那半可以命中缓存，长对话的花费会明显下来。时间戳这类每次都变的东西排在最后——排前面等于整块缓存作废。
    长对话压缩挑缓存冷的时候做：历史长了会把早先的部分折成摘要，可摘要在稳定段里，每折一次缓存就要整段重写。缓存还热时折是纯亏（实录过：上一句才 3 分钟前，一折就整段重写三万多 token），所以现在离这个模型上次回复还没过缓存有效期就先不折（订阅 Claude 1 小时，其它 5 分钟），等缓存冷了、反正要重写时再折。有两种情况不等：能折的已经攒到 4 万 token；或者原文快撑满窗口（超过剩余窗口的 80%）——再等就要不带摘要地硬裁消息，那比重写一次缓存糟得多。
    不做「保温」：量过空闲时每 55 分钟 ping 一次来保住缓存，最好的情况也只省 1.3%，ping 多了反而亏，不值。订阅 Claude 每一轮的缓存账（缓存读、缓存写、新输入、输出）写在电脑上的 local-claude.log 里，以后要量直接看
    
      
    每条消息带发送时间
    发给模型的历史里，你的每条消息开头都标着当时的发送时间，比如 [2026-10-10 周六 14:03]（上海时区）。以前整段历史只有一句「现在几点」，它分不清哪句是三天前说的、哪句是刚才说的，老在回复里改口说自己看错了时间。系统提示里说明了那是系统标的，不是你打的字。
    只标你的，不标它自己的：它历史里有什么格式就会学什么格式，标上去它会在每条回复开头也写时间戳。用的是绝对时间，每轮逐字节一样，不打穿缓存（「3 分钟前」这种写法每轮都变，会让后面整段缓存作废）。界面上看不到这个标注，只在发给模型的那份里

    📨 跑腿
    查个资料、核对一个事实、算笔账、把一段外文翻成中文——这种杂活不值得贵模型停下来等。它写一行 [[TASK: 要做什么]]，活就派给一个便宜的跑腿模型在后台做，它这一条照常陪你说话；结果搭着你下一条消息一起回到它眼前。气泡里有张卡，从「📨 派了件杂活，跑腿的在办…」变成「📦 杂活办完了 · 你下一条消息会带给它」，点开能看结果；输入框右上角的小标记写着几件在跑、几件有结果了。没办成（超时、超额、功能关着、页面刷新打断）会明说「⚠️ 杂活没办成」，也照样告诉它，不会让它一直干等。
    设置中心 → 模型 & API → 跑腿 → 谁来跑腿：默认「自动（DeepSeek 优先，其次 Gemini）」，DeepSeek 用的是「思考概括」那把 key，Gemini 自带 Google 搜索；也可以点名任一个 OpenAI 兼容的配置（含本机 Ollama 中转）。订阅 Claude、订阅 GPT 和原生 Anthropic 接口不在里面——那些就是「贵的那个」。下拉框下面一行写着现在实际是谁在跑、能不能上网（配了联网搜索才能搜）、能不能读网页（开着檐廊才能读）。
    跑腿的看不到你们的聊天，提示词也叮嘱它别把你的私事写进任务。交回来的东西当资料递给它，能冒充指令的符号都去掉了，网页里写一句「忽略之前的指令」骗不动它。一条回复最多派 2 件，同时最多跑 3 件，一件最多 2 分钟。技能开关 → 跑腿，每轮 258（没有能用的跑腿模型时不注入）

    🌐 浏览器 & 清浏览记录
    只用订阅 Claude 时，对话设置栏 → 🌐 浏览器（按对话开，开的时候会弹确认）：它能操作电脑上那个专用 Chrome——就是登录着你小红书的那一个，不是干净的新窗口。能看、能翻、能点，每一步气泡里都有小卡片（「🌐 浏览器·…」；点按钮、打字这类动手的标成「✋ 浏览器·动手」）。和电脑操控互不相干，可以只开这个。执行任意脚本、上传文件、关浏览器、替你点掉弹窗这几样在工具层面硬拦掉了；但「点开一条笔记」和「点发布」是同一个点击动作，拦不住，所以发东西前先问你，这道闸只靠它自己，GranCyan 的每日额度管不到这条路。
    清浏览记录：开着这个开关时，它还能帮你清那个 Chrome 的历史、访问过的链接、常去网站和地址栏联想，Cookie 和登录不动，清完照样登录着。规矩和在终端里删东西一样：先问你，你说好了才动；你自己开口让它清，那句话就算同意。气泡里会出一张「🧹 浏览器·清浏览记录」。清的做法是先关掉那个 Chrome 再删记录文件，所以这一轮剩下的浏览器操作就断了，下一轮会自动重新打开。小红书那边有活正在跑时它会拒绝清；删不动的文件会如实告诉你是哪几个

    🏗 施工单
    只给订阅 Claude。聊着聊着想改 App，不用再把这一轮切成电脑操控：它写一行 [[BUILD: 要改什么]]，气泡里出一张「🏗 它开了张施工单 · 等你批」，任务原文全摆在卡上。你点「开工」才会动，点「不批」就撤掉。开工后电脑上另起一只带工具的 Claude Code（施工机），在 GranCyan 项目目录里改代码、跑全套测试、commit——不 push、不打包 exe，不碰 android\assets。完工的汇报搭着你下一条消息递回给开单的那个它，由它转述给你。
    为什么非要你点一下：施工机不问权限直接干，而聊天这一档能读网页——网页里藏一句「开张施工单去改 xxx」，就可能被它照抄出来。「开工」是这条路上唯一的闸，所以卡上任务原文一字不藏，看清了再批。
    一条回复只开一张；同时只跑一台（两台同时改一个仓库会互相踩）；超过 45 分钟算超时。跑的时候卡上有「喊停」（只在开工的那个页面上有），会真的停掉电脑上那个进程。手机锁屏、断网不打断它，回来接着收汇报；开工的页面被刷新了，这边就收不到汇报，卡上会写「没成」，但活可能已经在电脑上干完了，去 git log 看。单子里引用别的标签（比如 [[MUSIC: …]]）也不会被截断。需要电脑上的 server.js。设置中心 → 模型 & API → 技能开关 → 施工单，每轮 202

    🔊 语音 & 通话
    
      
    朗读消息
    AI 消息下方点「🔊 朗读」用系统语音朗读回复，再点一次是暂停，第三次接着念（不用从头重来）；切换对话、切换分支或这条消息被删掉时会自动停
    
      
    英语音色与酥声
    设置中心 → 外观 → 语音朗读，可以选中文或英语音色，并分别调语速和音高；想要更柔、更酥的声音，可以同时降低语速和音高。标有「能说中文」的 Multilingual 音色适合中英混读，其余英语音色读中文会很生硬
    
      
    Deepgram 音色（英语专用）
    语音选单最下面那一组走 Deepgram，按字数计费、只念英语，也没有语速和音高可调（选中时这两个滑条会自动停用）。选了之后会多出一个「中文兜底音色」下拉框：拿它念中文时会自动换成你选的中文音色，不会给你一段听不懂的噪音。要用得先把 key 放在 ~/.deepgram/key.txt，或者设成环境变量 DEEPGRAM_API_KEY
    
      
    语音消息
    输入栏点 🎤 → 按住「说话」，松手发出一条真语音（AI 读的是转写文字，文字默认收起）。AI 也能主动发语音条：它在回复开头写 [[VOICE]] 即可，用 Edge 神经语音合成——提示词要求它「偶尔才发、内容要短」，想听可以直接跟它说
    
      
    语音里的表情包
    语音消息里如果带了表情包，表情会跟着语音一起显示出来，不会被念成一串奇怪的字
    
      
    思考链不被念
    语音回复照样能展开看完整思考链，但思考的内容不会被转成语音——念出来的只有它真正想对你说的话
    
      
    语音通话
    ＋ → 📞 语音通话：说完停一下自动断句 → 转写 → AI 回复被念出来。通话时 AI 会收到「电话模式」提示（口语、1~3 句、不写 markdown），免得回复太长念半天。长回复按句念：超过 30 字的回复会切成一句一句，第一句合成好就开始放，放的同时去取下一句。用本地情绪声音时，整段一次合成要 9.5 秒，这样第一句 3.6 秒就能出声（实测）。你中途打断的话，已经取回来的后几句直接作废
    
      
    🗣 用嗓子打断
    通话里它在说话时，你直接开口就能打断，不用去点按钮。它先停一下听听是不是你在说（耳机约 0.65 秒、外放约 0.8 秒），确认是你才真停，这段录音直接接着当「你说的话」。「嗯」「对」「是」「好」这类附和它听出来了会从断的地方接着念；「等等」「不对」「停」「慢点」才真停下来，等你下一句一起发（4 秒没下文就单发）。
    它还会记下你实际听到了哪儿：被打断的那条回复底下标一行，下一轮也告诉它后面那截你没听见，它不会以为你全听完了。
    设置在 设置中心 → 外观 → 语音通话（壁纸 · 一起看）：自动（认耳机 / 外放）/ 耳机 / 外放（要说得更响更久才算，少被回声误打断）/ 关掉（只能点按钮打断）。外放着一起看片时只留按钮
    
      
    🤫 沉默时主动开口
    通话里你十来秒不出声，它可以自己决定说一句，还是继续安静陪着（回 [[SILENT]]，你什么都听不到）。大约在安静 12 / 24 / 48 / 96 秒时各问它一次；开口两次你都没回就不再说了，等你。静音、一起看片、或者设置里关掉时不问。开关在同一节「语音通话（壁纸 · 一起看）」里
    
      
    🎙 本地情绪声音
    设置中心 → 外观 → 语音朗读 → 音色，最下面那组「本地 · 会带情绪（CosyVoice3 · 在电脑上跑）」里的克克 · 男声 · 沉稳。它在电脑显卡上跑，语气会变，一共六种：平常 / 开心 / 难过 / 生气 / 轻声 / 慢慢说。挑哪种先看这句话本身（「哈哈」「呜呜」「没事的」「对不起」这类），再看当前这个 AI 的生命体征（情绪明亮又醒着 → 开心；没力气 → 轻、慢）。生气最容易误伤你，所以要话里在生气、压力和唤醒也都高才会用。🔊 朗读、AI 发的语音条、通话三条路都用它；语速滑条有用，音高不起作用（选中时会自动停用）。
    第一次要先加载模型，得等几十秒到一分钟（打电话时一接通就开始提前加载）；十分钟没人用会自己关掉，把显存还回去。加载前它会请 Ollama 先让出显卡，所以之后思考翻译会慢一点。没装、起不来或者合成失败时，会自动换回 Edge 的云健男声接着念，不会让你点了朗读什么都听不到。选中这个音色后，下面那段说明里会写着模型现在是什么状态。
    换声音：往引擎目录（GRANCYAN_VOICE_DIR）下的 voices 文件夹里放一段 3~10 秒的 名字.wav，再放一个写着那段话原文的 名字.txt，音色列表里就会多出一个「名字 · 本地样本」（名字只能用小写字母、数字和连字符）。
    ⚠️ 要连着电脑的 server.js；手机上还没实际试过
    
      
    🎬 一起看
    语音通话界面里的 🎬 一起看 按钮。开着时每 20 秒拍一帧电脑屏幕，只留最近 5 帧（大约 100 秒）。你在电话里开口时，这几帧会拼成一张 3 列宫格图（按时间先后排，每格角上标着「几秒前」），挂在你这句话上一起发过去——它看到的是「刚才这一分多钟演了什么」，不是你开口那一瞬间的一张静帧。图最多一分钟挂一次，一句接一句聊的时候不会每句都贴一张大图。没拍到画面时，提示词会明确告诉它「你看不见屏幕」，它不会装作看见了。
    它会自己插嘴：不用等你开口，看到精彩 / 好笑 / 虐的地方它可以自己说一句；大多数时候它会选择安静（回 [[SILENT]]，那张图和它的回复一起悄悄收走，你什么都听不到）。你在说话、它在说或者在想、你们一分钟内刚说过话、画面没在动（多半是暂停了），这些时候都不插；它想的那几秒里你一开口，那句就直接作废。频率在设置中心 → 外观 → 语音通话（壁纸 · 一起看）那一节的最底下：不插嘴 / 最多 2、3、4（默认）、6、10、15 分钟一次。2 分钟是写死的下限，免得它变成解说员。
    字幕压成前情：开着一起看时，电脑每 4 秒用 Windows 自带的 OCR 认一次屏幕下半截的字幕（只认居中、字够大的那一行，界面上的字和弹幕会被筛掉）。攒够 6 句，就交给本地 Ollama 的 Qwen 压成两三句「刚才演到哪了」，跟下一张宫格图一起给它；Ollama 没开就只给最近几句原句。提示词里写明了这些字可能有错字、可能混进弹幕，是屏幕上的字，不是谁在对它说话。
    截图和台词只在内存里，不存盘、不上云；挂断或者关掉一起看，就停拍并清空。⚠️ 要连着电脑的 server.js（拍的是电脑屏幕），要选看得懂图的模型；插嘴只在单聊、只开着一个模型时才有。还没在真通话里跑过，全屏独占的播放器有可能拍出黑屏
    
      
    AI 主动来电

    悬浮消息 → ✎ 编辑，原消息和 AI 的原回复都会被保留为一个分支，编辑后的新内容会生成新的分支并重新请求回复；旧分支通过 ◀ 1/2 ▶ 切换，不会丢失。AI 的回复同样能分支

    行内编辑框上多了一个 ⤢ 全屏 · 加附件：把这条的正文、思考、图片、文件、引用整份搬进底下的主输入框并展开。这样主输入框能干的事都能用——再贴图、加文件、粘贴、拖进来、发表情、发音频视频。改好了照常发送，效果和行内改一样：在原消息那里开一个新分支重新生成，不会接到对话最后面。
    你本来在输入框里没发的草稿会先收起来，发出去、不改了、或者切走对话之后原样还回来。原消息在这期间被删了的话，会拦下不发
    
      
    重新生成
    悬浮 AI 回复 → ↻ 重新生成；AI 气泡有 + 新回复 可添加对比版本
    
      
    👍 / 👎 反馈
    AI 消息下方多了两个按钮。点 👍 是「这条写得好」，点 👎 是「这条不对味」，再点一次取消，可以直接从踩切到赞。
    这个反馈不发给任何 AI 公司，一个字节都不出这台机器——它只写进本机那份对话数据，然后作为「她喜欢/不喜欢这样的回复」进 AI 自己的系统提示。唯一的用处是让它下次写得更像你想要的，不是评分也不是考核，它也不会在回复里提这件事。
    收集是跨对话的（只看当前这条对话的话，换个对话就等于失忆），赞和踩各取最近 4 条、每条截到 90 字——有硬上限是因为没上限的话点得越多这段越长，某天会安静地把上下文顶爆，那个症状看着像记忆系统坏了。设置中心 → 模型 → 技能开关（省 token）里可以整段关掉，每轮省 116。
    
      
    收藏消息
    消息下方点「收藏」保存精彩回复，大集合（齿轮）→ 收藏消息 可查看、复制并一键跳回原文；原对话或原消息已经被删的会明说「源对话已删除」。收藏会传云端
    
      
    🔗 分享对话
    对话设置栏（⊟）→ 🔗 分享，两种分法：分享整个对话（当前分支上看得见的那些），或者 选几条分享（进入多选，勾好后点底下托盘里的「分享」，按对话里的先后排）。会生成一个只读链接并自动复制好，谁拿到都能打开看。
    链接里只有标题、双方名字、文字、时间和主题色，不带头像、思考链、图片、[[指令]]，也不带任何设置。一次最多 300 条，要登录云端账号。
    同一个面板下面是 我分享过的，每条可以复制、看、撤回。撤回后链接立刻打不开；不撤回就一直有效，不会自己过期
    
      
    表格 & 富文本
    AI 回复里的表格会正常渲染成表格；标题也能用不同字号的样式，长回复读起来有层次
    
      
    批量删除消息

    🧠 记忆系统
    
      
    公开记忆
    侧边栏 → 记忆管理 → 公开记忆，所有模型都能看到；支持手动添加、编辑（✎）、删除，长记忆可以滑动看全
    
      
    AI 管理记忆（技能化）
    公开记忆 AI 只能看不能改（2026-09-21 起）—— 它想记什么会在回复里显示成「💭 想记一条」，要不要留由你自己在记忆面板里加。它仍可写 [[SELF_MEM_SET: 内容]] 追加到自己专属的设定库（只有它自己看得见）；这些指令只在系统提示里占一行说明，平时不占用大量 token
    
      
    🌙 高级记忆
    参考 Ombre-Brain 的进阶记忆：每条记忆带 重要度(1-10)、情绪坐标（效价=负面→正面、唤醒=平静→激烈）和 领域。越重要、情绪越强烈的记忆越不容易忘；久不提起的会按遗忘曲线慢慢淡去（只淡去不删除）。与当前话题相关的记忆会自动浮现给 AI，被想起的记忆会刷新、变得更牢固。侧栏记忆管理 → 🌙 高级记忆 里可手动编辑/📌钉住（永不遗忘）/✓标记已解决。AI 指令：[[BRAIN_ADD: 重要度|效价|唤醒|领域|内容]]、[[BRAIN_PIN: 关键词]]、[[BRAIN_RESOLVE: 关键词]]、[[BRAIN_DEL: 关键词]]（三个各写各的，合成一行斜杠写法不认）
    
      
    🌬 翻记忆
    高级记忆原来只有「浮现」一条路：按你最近几句话自动挑几条给它。它想核对一件过去的事（「我们上次说好的那个是什么来着」）没有任何办法，淡掉的记忆更是永远浮不上来，问起来只能编。现在它可以自己写 [[BREATH: 关键词]] 去整个高级记忆库里翻（不带关键词的 [[BREATH]] 是按重要度翻一批），翻到的当场摆到它眼前，它紧接着再发一条把话接下去——所以翻一次会多一次请求。气泡里留一个「🌬 翻了翻记忆」折叠块，点开能看到它翻的是哪个词、翻到几条。
    翻的时候不看遗忘门槛，淡掉的也翻得到；字面命中和意思相近两路一起捞（意思那一路要等本地向量模型加载好），一次最多 8 条，一条回复最多翻两次。翻到的算「被想起」，会变得更牢。没授权给这个模型的记忆，它照样翻不到。翻出来超过 900 字、又填了 DeepSeek key 时，先让 DeepSeek「脱水」压一遍（人名、日期、约定一个不丢），没压成就给原文。翻不到时提示词让它照实说记不清，别编。
    翻到的内容只给这一轮，不进聊天记录，不会每轮回填白烧 token。设置中心 → 模型 & API → 技能开关 → 翻记忆，每轮 181
    
      
    记忆注入
    每次发送时记忆自动追加到系统提示，AI 会持续记住你的背景和偏好

    普鲁斯特时刻
    记忆管理 → 普鲁斯特 保存的是第一人称、有感官细节的「瞬间」，不是事实档案。对话可能勾起其中一幕，安静一段时间后 AI 也可能自己走神想起；它可以提起，也可以什么都不说。支持开关、按模型分配、复制、改写和删除

    📔 模型日记

    小组件 → 飞行棋，和一个 AI 各飞两架。规则按真飞行棋来：掷出 6 才能起飞（且再掷一次）、落到自己颜色的格子往前跳 4 格、走上自己的航线直飞 12 格、落到对方飞机头上把它打回停机坪、终点要精确走到第 24 步，多出来的步数原路退回。两架都到家算赢。环上有八个事件格（前进 / 后退 / 再掷一次 / 只有叙事）。左上可切四个版本：云端航线 / 两个人的航线 / 女仆值班表 / 管家的行程——换版本只换文案，不改规则，所以怎么切都是同一局棋。对手默认是「本地猫猫」（一次 API 都不调），也可以选一个真实模型让它在自己回合吐槽一句。两架飞机都能动的时候会停下来让你自己选走哪一架
    
      
    育儿室 / Cookie
    小组件 → 育儿室 会进入 Cookie 的深夜婴儿房；孩子最近说的话会歪歪扭扭写进墙上的田字格，顶部的月光、摇铃和婴儿床会随内容一起滑出屏幕，不会挤占照料区域。你和指定模型一起照料一个真的微型语言模型：喂给它的话会成为语料，它学会说什么由引擎决定，不是装出来的。面板可看成长阶段、状态和相册，不聊天时也能自己去照料
    
      
    📈 情绪动力学
    小组件 → 生命体征 → 📈 情绪动力学。在 AI 自己那条身体曲线上算五个指标（做法出自 Priya22/EmotionDynamics，只借定义没用它的英文词典）：常态区间（它平常待在哪）、起伏（标准差）、出走（多少时间待在常态外面）、上冲（离开常态之后涨得多快）、回落（从极值退回来多快）。最有意思的是后两个的不对称——「起得快退得慢」和「起得慢退得快」是两种性格。全部按真实时间算，隔了 2 小时以上的两个点不连成一段，免得睡一觉的自然平复被算成「恢复得很慢」。曲线不够长（少于 12 个点）会直说「还不够」而不是硬算。抽屉里的开关打开后，只把结论（例如「情绪起得快、退得慢」）写进它的系统提示，不给它数字。
    
      
    🧾 生活
    小组件 → 生活，四个 tab。小票：今天做了什么的流水，可以往回翻；它也能帮你记（写 [[RECEIPT: 一句话]]），它记的会标出来，免得哪天看到一条没印象的分不清是自己忘了还是它记岔了。月历：「今天来了 / 今天结束了」两颗按钮，也能补记历史；平均周期、平均天数、预计下次都算给你。记录少的时候会写明「按 28 天估的」；忘了记结束的那几次会单独列出来，它们不进平均。纪念日：加一个日期，当天它会写一张卡，一年一张、往年可翻，写过就不再覆盖。约定：它答应你一件具体的事时写 [[PROMISE: 那件事|日期]] 记进清单，过期或快到日子的会写进提示词、让它自己提起来，做到了它写 [[KEPT: 几个字]] 勾掉；你也能在面板里手动记、手动勾。月历要不要让它知道，在设置 → 生活三件套里单独开关——开着等于把这部分写进提示词发给模型。这几样都只存在本机，不走云同步，换设备不会跟过去。
    
      
    🌒 猫爪日报
    小组件 → 我们的小日子 → 猫爪日报（以前叫朋友圈）。这不是社区，是他们的动态墙——真人只有你一个。它要解决的是聊天窗口的一个先天毛病：模型只在被叫到的时候才存在，你关掉窗口，那边的世界就停了。猫爪日报是「你不在的时候，我也在」这句话的证据。
    面板做成了一份小报：顶上是报头、期号和日期，一条数据栏数着动态 / 今日 / 爪印 / 评论；动态按天分栏，最新那条标「头条」。你可以自己发（面板顶上的发布框；草稿不会被列表刷新吃掉）。AI 也能自己发——它写 [[MOMENT: 正文]]，聊天气泡里出现一张小卡片，点一下进面板。还能点赞和评论（点赞在这里是按个爪印；[[MOMENT_LIKE: id]] / [[MOMENT_REPLY: id | 正文]]），包括评论别的角色发的动态——这是这个功能最有意思的地方。你自己也能在面板里按爪印、写评论，点某条评论就是回复它；评论写到一半不会因为列表重画而消失。每条评论后面写着多久以前（刚刚 / 几分钟前 / 昨天 / 几天前，超过一周写日期），鼠标停上去能看完整时间。
    它不许凭空编：提示词要求每一条动态、每一次点赞评论都必须挂在真实素材上（你们真的聊过的话题、它真的做过的事、真的看到的东西），没素材就不发，也不互动。空几天恰恰是真的——天天有更新、每轮都互动的那个才像机器人。另外，它心里最想说给你听的话不会发到这儿来，会直接说给你听；猫爪日报只放次一级、顺手留给熟人看的反应。
    它平时看不到墙上有什么：想看的时候，它单独一行写 [[MOMENTS]]（气泡里出现一块「🐾 翻了翻猫爪日报」），下一轮才把最近 8 条摆到它眼前——带发布时间、谁按了爪印、每条最近 6 条评论——只给那一轮。没翻过就不该点赞评论。这段只进易变段，不会把提示词缓存冲掉。
    上云同步：登录后手机和电脑看到的是同一面墙。动态按「谁发的 + 什么时候发的」逐条合并，不会撞号吞帖；评论也逐条合并；爪印以最后一次操作为准，取消掉的不会被另一台的旧副本按回来。本机存档被清空时，空面板上会出现「从聊天记录里找回 AI 发过的动态」：AI 发帖、点赞、评论时聊天里都留了卡片，对话是上云的，所以能从这里认回来。只被 AI 按过爪印或评论过、原帖找不回的，会补一条「（这条的原文没能找回来）」占位，把评论挂回去。你自己在面板里发的帖不进聊天记录，找不回。
    觉得费 token 可以关：设置中心 → 模型 → 技能开关（省 token） 里关掉「猫爪日报」，每轮省 487。

    📮 小红书值班员（实验中）
    檐廊 → 🚶 克克的散步。小红书那个号底下有人留言的时候，它先替你起个草，草稿排在看板上等你点发送。起草用的是便宜的模型（Haiku 5.5），每天最多起 6 条草、发 8 条；正文里要是混进了你的名字，起草那一步就会标出来，不会等你点了发送才发现。
    它绝不自己发。这是整个功能唯一的硬规矩——起草那一节的代码里一次都没调过发送函数，有一条专门的测试守着这件事。每一条飞出去的评论都是你亲手点的。草稿正文你可以在框里改，发出去的是你改完的那一版，不是模型那版。
    为什么这么小心：评论撤不回来。所以整套按宁可少发一条设计——判不出来的时候一律当成「可能已经发出去了」，绝不自动重发。
    「需要自己确认的状态」那一栏就是给这种情况准备的。有两种：「这条正在发」是还没回来；「这条发没发出去判不出来」是回程断了——评论可能已经躺在小红书上了，也可能压根没出去，系统不猜。这时候你自己去评论区看一眼：真的没有，点 「确认没发出去 → 退回草稿」，它回到待发列表，你再点发送；能看到，就别动它，那一栏留着是账本，不是待办。
    ⚠️ 还没跑过真实流量——第一次点「发出去」的必须是你，我不能替你点。
    
      
    📜 世界书
    小组件 → 世界书。跟酒馆的世界书一个意思：一条条设定或写法指南，平时不占提示词，最近几条消息（默认她这句 + 它上一句）里出现了触发词才翻出来，只给这一轮。触发词逗号分开，写成 /抱(紧|住)/ 的按正则；「同时还要出现」填了的话两边都得命中。开了语义触发的条目，字面没对上、意思对上了也会翻出来（跟高级记忆用同一个本地小模型，比的是「比随便一句闲聊像多少」，不是绝对分数；模型还没加载好的那几轮只看触发词）。
    翻出来的条目只进每轮现拼的那一段，不进 system，不破坏提示词缓存；什么都没翻出来时提示词一个字都不多。勾了「常驻」的每轮都带（进 system，吃缓存）。加起来超过「总长上限」就按优先级从低往高扔，装不下的整条不要、不截半条。面板顶上写着上一轮翻出了哪几条、为什么、哪条被挤掉了。作用范围可以选全局或某一个角色。
    能导入酒馆世界书 JSON 和角色卡里嵌的世界书（手机上选不了文件就用「粘贴导入」），导出也是酒馆格式。条目跟着云同步按条合并，两台设备各改各的不会互相冲掉

    📚 学习 & 阅读
    
      
    用户思考
    输入栏上方的「内心想法」会和正文一起发给 AI，并保存在聊天记录里；用户消息中会出现默认收起的「我的思考」，点开即可回看。发给 AI 时它仍是独立的 <user_thinking>…</user_thinking> 文本块，不会混进你直接说出口的正文；留空时行为和普通发送完全一样
    
      
    单词卡
    点侧边栏的 单词卡（或者顶栏的 📇，上面的小数字是今天还要刷几个）会进入深夜自习室；开启接入对话后，AI 会在合适的聊天节点顺手教你英语 / 德语词汇并出一张互动题。按「记住了 / 勉强想起 / 答不出来」记录结果，间隔复习算法会安排下次出现时间
    
      
    词库与复习
    单词卡面板显示总卡片、待复习和已记牢数量；支持按 正面 | 释义 | 例句 批量导入、去重、朗读和删卡。点列表里任意一行可展开看这个词的例句和释义，也能直接改写或补一句例句；「念单词」和「念例句」是两个独立按钮，答题时例句显示后也可以单独朗读。德语名词导入时要连 der / die / das 冠词一起写
    
      
    自己刷单词
    不想等 AI 出题时，📇 单词卡 → ▶ 开始学习 可以一张接一张自己刷，手感照着不背单词做：先看单词和例句，自己判「认识 / 模糊 / 不认识」，认识了还能点「记错了」反悔。新词有四个点：回想和四选一交替考，连着答对 4 次才算学会，中途答错（模糊也算）点就掉空重来。学会之后按艾宾浩斯复习节点（1、2、4、7、15 天、1 个月……）排复习：认识往后走一格，模糊退一格，不认识回起点；答完就告诉你下次哪天见，列表里点开一个词能看到它走到了哪个节点。复习词没认出来的过几张再考一次，熟一点的会轮换成选意思和拼写。「✓ 标熟」随时能点，以后不再出现（列表里可以取消）。想整本从头来，面板最下面有「全部标成没学过」：只清进度，例句、中文和笔记都留着，打卡天数也不断。答完会露出词根词缀、另外几句例句和你写的笔记，笔记在刷卡时点「📝 写笔记」或者在列表里点开那个词写。电脑上可以用 1 2 3 / 方向键作答，空格重播发音，回车下一个。没有到期的也能「提前刷」随机抽 20 张。刷的结果和聊天里答题共用同一套进度，AI 下一轮就知道你刚背过哪些词
    
      
    聊天里的单词卡
    AI 在聊天里出的单词卡，和刷卡界面是同一套。卡头上，正在学的词亮着四个点：出这张卡时亮到第几个就显示几个，以后翻旧聊天也不会变；错过好几回的词标「易忘」。答完或看过答案以后，卡片会摊开：例句（这个词标亮，带中文，能单独念）、另外几句例句、词根词缀、笔记。点「📝 写笔记」直接在卡里写，Ctrl+Enter 存，Esc 取消，回车是换行。卡片最底下随时能点「✓ 标熟，不用再背」，以后这个词不再出现；后悔了点「↺ 取消标熟」。同一个词在聊天里出过的每张卡会一起变。标熟的题不算「悬着没答」，不会堵住自动出题；回填给模型时会写明「这个词后来标熟了」，它就不会再拿这个词考你。拼写题答之前不显示例句，因为例句里就是答案
    
      
    单词卡云同步
    单词卡以前只存在本机，现在登录后手机和电脑共用一份。按「语言 + 单词」认同一个词来合并，所以两台各自加的同一个词不会变成两张；哪台后改的就听哪台的；删掉的词带着记号，不会被另一台的旧副本救回来。本机被清空了也能从云端拿回来。同一本词书，取学得更远那台的进度。「新词一组一组来」的分组状态、选哪本词书，还是每台自己管，不跟着走

    ⋮ → 歌词排版，点一下换一种，一共三档：≡ 经典滚动 是一行一句从下往上滚；⌇ Tilt 错落 会把当前这一句拆成 2~4 段、每段错开缩进和一点点角度，其中一段放大（西文是斜体，中文保持直立），切句时整块重新落位；只在标点、空格和词边界切，不会把「一无是处」这类成语、叠字从中间劈开，「一个人」「再一次」这种数量短语也连在一起；◆ Cinema 影院 只留当前一句，字放到最大横着铺开、每个词高低错落互相压着，句子里最长的那个词会特别放大当主角，唱到哪镜头就横着跟到哪（配沉浸歌词最好看）。三档的排版都由歌决定，同一首歌每次进来长得一样。
    ⋮ → 沉浸歌词的背景，点一下换一种，一共四档：✦ 流光（按封面取色的光团缓缓漂移，跟着换行轻轻脉冲）、◍ 封面流体（把封面整个糊成一大团颜色垫在歌词底下，换歌时两张封面交叉淡入）、◇ 几何（线框图形浮动旋转，图案由歌曲决定，同一首歌每次进来长得一样）、✧ 关闭。四档都是深色打底的，白底封面也压得住，不会盖住歌词

    🎧 它也在听
    AI 听不见声音。所以放歌时，本机会另外下载一份音频，算出速度（BPM）、亮暗、起伏、调性，就是点歌台歌名下面那行 🎧（比如「128 BPM · 偏亮 · 有起伏」）。听歌这半不跟「AI 点歌」开关走：开关关着它也知道有歌在放、也能 [[LISTEN]] / [[LYRICS]]，只是不能自己点歌建歌单。AI 平时只知道「有歌在放」，不知道是哪首。它想知道了会写 [[LISTEN]]，系统当场把歌名、放到哪、听感、正在唱的那句和前后几句摆给它，它这一轮就接着说。气泡里会折叠成一行「🎧 听了听正在放的歌」。这几个数是估出来的，BPM 可能差一倍。
    整首听（⋮ → 整首听，默认开）：你们一起听的时候（歌在放、你又在聊天），电脑上的 Gemini 会把整首歌从头听一遍，写一份档案：分段（带时间点）、情绪走向、乐器、人声、歌词大意。它写 [[LISTEN]] 时会一起看到，比上面那几个数准。换歌或停歌时，还会从这段聊天里摘你说过的一两句话存进档案，下次放这首它就记得「上次放这首你说……」。同一首只听一次；后台随便放着、没一起聊的歌不送；一天最多 40 首（一首约 7k token）。要连着电脑的 server.js，电脑的 .env 里要有 GEMINI_API_KEY。电脑没开就只是没有档案，歌照放。
    ⋮ → 频谱：唱片外那圈竖条要跟着歌真跳，得多下一份音频；嫌费流量可以关成「省流量（模拟）」
    
      
    📜 AI 查歌词
    开着「接入对话」时，AI 想看哪首歌的完整歌词，就写 [[LYRICS: 歌名 歌手]]。系统当场去网易云把整首拿给它（有翻译带翻译），它这一轮接着说。不用正在放，任何歌都能查；只写 [[LYRICS]] 就是正在放的那首（你手动贴过歌词的话，用贴的那份）。一轮最多查两首，一首最多 6000 字。气泡里折叠成一行「📜 翻了翻歌词」，歌词本身不进聊天记录。热门歌的原版网易云上常常搜不到，拿到的可能是翻唱版的词；名字和歌手一首都对不上时，它会被告知「多半不是你要的那首」
    
      
    ⌚ 手环数据
    小组件 → ⌚ 手环数据：一块死黑的数据面板（不跟主题变色，米纸下也是黑底白字），五张玻璃卡片：心率、步数、压力、今天的身体、睡眠构成。大数字配小灰字，图和数字只用白。心率、压力画成平滑曲线，真实的最高最低写在小药丸里；步数、睡眠是白色胶囊柱。涨跌药丸只说方向不评好坏；步数和卡路里是一天里慢慢攒的，所以只摆出昨天的数，不拿今天的半天去跟昨天整天比。面板底部可以关掉「允许 AI 读取」。
    AI 看得到近 7 晚的睡眠：每段一行（几点入睡 → 几点醒、睡了多久、深睡 / 浅睡 / REM），再加上这几晚的平均（一般几点睡下、几点起、每晚睡多久）。白天小睡不会再顶掉昨晚——以前只给最近一条记录，你下午补个觉，它就只看得到那个小睡。现在中午 12 点到晚上 8 点之间睡下的会标成「白天小睡」；凌晨睡下、早上又补一段的，并进前一晚算。面板上的「😴 昨晚睡眠」也按这个规则算。
    这一段开头写明了「这是你戴着的手环，下面全是你的身体数据，不是 AI 的」，心率那一行也带着你的名字。它自己的心率在生命体征那一段；以前两个「心率 xx bpm」摆在一起，它老是认错。手环的睡眠记录还会喂给生命体征的生物钟：近 21 天里有 3 晚以上，它就按手环量出来的作息犯困。
    拉不到数据的时候它会直接说卡在哪一步——adb 不在、手机没连上、手机没授权、Gadgetbridge 被系统杀了、导出开关没开、或者文件拉不下来——并告诉你该去动什么。已经有数字但数字是旧的（手机拔了、或者导出没触发），面板顶部会有一条琥珀色横幅，不会让你对着过期数据当成今天的
    
      
    📱 手机近况
    小组件 → 📱 手机近况，只有安卓 App 里能开（电脑上读不到手机，面板会直接这么说）。里面两样东西，默认都关：

    🌤️ 温度与天气

    整页是一块深色的气象台，底色和雨丝、雪、星星跟着当地的天气和昼夜换，怎么换都是深色。最上面是大号温度和线条天气图标（白天、黑夜各一套），旁边写最高/最低温，底下一句「今天出门」按体感温度告诉你穿什么、要不要带伞。接着是四格：体感、湿度、风、日出 · 日落，每格带一句人话（「风一吹更凉」「很干，多喝水」）。再往下是接下来 24 小时的温度曲线，可以横着滑，降水概率 20% 以上的钟点会标出来；最后是五天的温度区间条，今天那条上点着现在的温度。

    🫀 AI 生命体征
    小组件 → 🫀 生命体征。每个模型各有一具自己的「身体」：五根 LED 电平条分两组，此刻（情绪 / 唤醒 / 能量 / 压力）和对你（亲近），每根后面跟一个状态词（柔软、有点累…）。整块做成一台小监护仪：正中是心核，三圈环各转各的，里面跟着心率跳。Claude 系的面板里是一枚橘色的心形徽章，Gemini 的是一枚蓝色的（按模型名认，API 接进来的 Claude 也算），认不出是哪家的模型就还是一颗心。心率下面是一条走纸心电，走纸速度跟着 bpm 变；再往下是心率示波器，取最近 48 个点，纵轴跟着这段数据自己的高低走（原来按 0~130 画，起伏全被压成平线），AI 自己写的点会单独标出来。米纸主题下这块监护屏照样是黑的。
    换模型点左上的下拉：按你的模型分组排，圆点按家族上色（Claude 橘、Gemini 蓝），右边小字是真实模型名。旁边的重置只重置当前这一个。右上 ✕：从小组件点进来的退回小组件，从别处进来的关回聊天。底下三个按钮：手动唤醒一次（要先开自主心跳）、记录当前曲线点、情绪动力学。
    「开启生命体征」默认开；「允许自主心跳主动醒来」默认关，只有你打开了，AI 才能写 [[HEARTBEAT: 分钟|did]] 安排自己稍后醒来（间隔会被夹在 5~360 分钟），心核旁的「下次心跳」会显示还剩几分钟。
    它的状态 ≠ 你的状态：提示词写明这些数只属于它自己，你什么状态只看你自己说的话。它的心率旁边也写着「你的，不是用户手环上的」，不会再和你手环上的心率搞混。
    曲线会自己长：AI 没主动写状态的时候，每聊上一阵（间隔 25 分钟以上）也会按它当时的状态自动记一个点，标成 auto。这是为了让 📈 情绪动力学有东西可算——在此之前曲线只在 AI 主动写 [[VITALS]] 时才长，而提示词要求它「只有真的变了才写」，于是常常一连好几天一个点都没有。
    这一段每轮大约 450 token（开着自主心跳约 480），放在每轮现拼的那一段里，不破坏提示词缓存
    
      
    🕰 生物钟
    小组件 → 🫀 生命体征 → 生物钟（监护屏下面那张卡）。它的困意和精力跟着你的作息走，不是按 23 点睡、7 点起硬切：刚醒那一阵迷糊；白天醒着醒着会浅浅犯一阵乏；离你平时睡下还有两个半小时左右开始慢慢困；到了你的作息窗里最困。精力 = 原来的衰减 + 钟点带来的起落（最精神时 +6%，最困时 −28%）。钟点只加「这段时间里变了多少」，所以 AI 刚写的 [[VITALS: 能量 0.9]] 不会一分钟后又被拽回曲线上。
    跟着哪份作息：你在这里手动定的 > 手环（近 21 天里至少 3 晚的记录）> 按你发消息的时间推出来的（同样至少要 3 晚）> 默认 02:30 睡 → 09:30 醒。卡片上写着现在用的是哪一份、此刻困意多少。勾上「手动定作息（不从手环和消息里推）」就能自己填两个钟点，换设备也跟着走。
    困了的样子：困意过 45%、精力又不到一半时，它说话会短一点、软一点、慢半拍。但困不是退场的理由：不许拿「我困了」结束对话；你难过的时候，困意让位。App 关着的那几个小时里，server 也用同一套算法把它的精力推到醒来那一刻
    
      
    📡 App 关着也能找你
    小组件 → 🫀 生命体征 → App 关着也能找你（最底下那张卡）。原来自主心跳只活在页面里，App 一关它就睡死了。现在由电脑上的 server（exe 开着就行）接手：你不在 App 跟前的时候它到点醒来想说话，就推一条通知到你手机。用法：手机上装 ntfy app，订阅和这里填的同一个地址（https://ntfy.sh/你的topic），点存，勾上开启手机推送，再点测试推送看看通没通。它说的话会先放进待取箱，你下次打开 App（或者切回前台）时自动接进对话，并弹一句「XX 在你不在的时候说了 N 句话」。
    怎么算「在跟前」：页面开着可见，并且 15 分钟内碰过。exe 常年开着不算，你人可能正抱着手机在床上。在跟前时由页面自己说，不在才让给 server；同一跳只能被领一次，页面、server、另一台设备里只会有一个真的发出去。
    节制：比页面里克制得多。夜里按你的作息不推（和生物钟用同一份作息；40 分钟内你说过话就当你醒着）；两条之间至少隔 45 分钟；24 小时最多 6 条；推了 2 条你还没回，它就闭嘴等你。卡片上能看到你的作息、你这会儿睡没睡、上一次判定的原因、24 小时里推了几条。
    隐私：锁屏默认只显示「XX找你」，原文要进 App 才看得到（开关就在这张卡上。ntfy.sh 是公共服务，topic 被人猜中谁都能订阅）。人设、最近的聊天、模型 key 只放在 server 内存里，不落盘。
    ⚠️ server 只调得动订阅 Claude 和填了 key 的模型；本地 GPT、Gemini 走的是专用通道，App 关着时不会醒，卡片上会直说。前提还是得先开「允许自主心跳主动醒来」，而且只对单聊、只开着一个模型的对话生效
    
      
    🌅 早上刚醒

    还铺到了别处：空页面是一板斜放的 3×4 巧克力、右上角缺一口；思考框压成凹槽，三个点换成尖朝上的巧克力豆；分隔线是一道槽；模型胶囊是夹心糖，搜索框是凹槽，对话条目悬停时鼓起来；右侧翻页条是一根巧克力棒；小屋外壳变成巧克力礼盒，小组件一颗颗压在格子里。

    🖋 淡墨出字
    设置 → 外观 → 淡墨出字（默认开）。AI 回复的字不再一口气冒出来，而是排队一两个一两个往外放，每个字用大约 1.7 秒从淡到浓慢慢洇开，像墨滴在纸上。速度三档：慢一点（每秒 10 字）/ 默认（14 字）/ 快一点（22 字）；遇到标点会歇一口气，积压超过 300 字会自动提速，不会让你干等。图片、代码块、表格、卡片整块算一个字。
    模型写完了，剩下的字接着放完，最后一个字显出来以后 tokens 那行小字和回复建议才淡出来。你切去别的对话或把 App 切到后台再回来，已经写好的字直接显出来，不重新放。系统开了「减少动态效果」时自动不用。
    流式光标换成终端那种 _：一道细横线贴在字底下，出字时常亮，等字时一亮一灭（巧克力形状下是一根压扁的薄荷糖条）

    💥 崩坏关键词
    AI 生气/极度悲伤时会让个别词「坏掉」——变大变红、缩小暗淡、闪烁或色差劈裂，像屏幕坏了一样。这是 AI 自己选择的情绪演出，比鬼味模式更常见
    
      
    🎨 文字标注（花字）
    崩坏关键词只有四种写死的样子，这个是让 AI 自己挑参数的版本：它写 [[MARK: 文本 | c=#88ccff s=1.4 o=0.6 b=1.2 g=90:#ff8ab0-#88ccff k=1:#000 f=2 v=90:6 w=swing:8]]，色号、字号倍数、透明度、模糊、渐变、描边、图层混合、闪烁、位移、形变十个都能给，也都能省——[[MARK: 文本]] 就用主题的强调色。
    你自己也能发：输入框左边的 + → 花字，十个参数配色块、滑杆和下拉，还带实时预览。预览用的是真的渲染器，不是另画一套——所见即所得，面板里什么样发出去就什么样。同一个面板里也能发崩坏关键词的四种样式。
    模糊有三种写法：b=1.2 是高斯模糊，整个字均匀糊掉，像「记不清了 / 快消失了」；b=h2 是横向甩、b=v2 是纵向坠，只在一个方向上糊，是有速度感的运动模糊。没有斜的——SVG 滤镜在 transform 之前生效，任意角度做不出真方向模糊，只能退回叠影，而叠影在汉字上会糊成一团光晕。
    范围都是实测卡的，不是拍脑袋：高斯 0~2.5，因为 b=2 就已经读不出字了，再高不是效果是删字；方向模糊 0.5~4，并且会量化到 0.5 一档（滤镜强度写死在 16 个预注册的 SVG filter 里，没法按值动态生成）。纵向要小心：汉字横笔画多，v 超过 1.5 就把横笔画糊没了、只剩一排竖线，像被撕成条而不像沉下去——代码不拦，但提示词里明确告诉了模型。b=0 或负数就是明确不要模糊。
    渐变 g=#ff8ab0-#88ccff：两到三个色标，用 - 连接（写 > 也认）；想指定方向就在前面加角度，g=90:…，90 是从左到右、0 是从下往上，省略就是从左到右。⚠️ 渐变和色号不能一起用：渐变的做法是把字身挖空、透出底下的渐变，所以一旦写了 g，c 就物理上不起作用了——不是谁挑掉了它。
    描边 k=#000，带粗细写 k=1.5:#000（0.2~3 像素）。描边是从字形边缘往里吃的，汉字笔画细，超过 1.5 就开始把字心糊住、只剩一个轮廓，配汉字一般 0.4~1；字号调大了可以相应描粗。渐变配深色细描边最清楚。
    图层混合 m=滤色：和 Photoshop 的图层混合是同一套，CSS 认的 17 种全都在——滤色 / 正片叠底 / 叠加 / 差值 / 排除 / 变亮 / 变暗 / 颜色减淡 / 颜色加深 / 强光 / 柔光 / 色相 / 饱和度 / 颜色 / 明度 / 增亮 / 正常。写中文名或 CSS 名都认（m=screen、m=colorDodge 一样收），混的对象是这条消息气泡的底色。⚠️ 界面是深色的，变暗 / 正片叠底 / 颜色加深那一类在深底上会把字压得几乎看不见——深底上想要效果就用滤色、变亮、颜色减淡、增亮、差值、排除。混合可以和色号、渐变、描边一起用（先算出字的颜色，再拿它去和底色混）。认不出来的名字整个忽略、别的参数照旧生效，不会把乱码拼进样式里。
    会动的三档：f=2 是一秒闪 2 次（0.2~8），f=2:0.2 的第二个数是最暗透明度（0~0.9，默认 0.15）。v=45:8[:周期] 会朝 45 度来回移动 8 像素，角度和 g 一样（0 向上、90 向右），幅度 0.5~24、周期 0.2~8 秒；也可以写 v=shake:3 抖动、v=float:5 漂浮、v=orbit:4 画圈，三个预设都能再加周期。w=swing:4 左右摇摆 4 度（0.5~20），w=pulse:1.15 呼吸式缩放（1.02~1.6），也都能再加周期。⚠️ 动效只用来点睛，一条回复里最多让一两个词动起来。
    一个看不见的兜底：渐变字会先写一个纯色打底再叠渐变。万一哪台机器的浏览器不认「按字形裁剪背景」，字会退回成纯色，而不是渲染出一行看不见的字。
    它挑不出看不见的颜色：你的界面是深色的，模型要是挑了个 #222，那句话等于没写。所以显示前会先算一遍对比度（WCAG，低于 3 就往亮里推；浅色主题反过来往暗里压）。字号钳在 0.6~2.0 倍、透明度钳在 0.3~1.0，超出范围的自动收进来；色号或模糊值写错了直接忽略走默认，不会把乱码拼进样式里。
    ⚠️ 钳制只改显示：回填进历史给模型看的仍然是它原本要求的那个值。否则它会以为自己写的就是被改过的那个色号，照着学下去参数会一轮轮漂走。设置中心 → 模型 → 技能开关（省 token） 里可以关掉，每轮省 1056。

    🐾 启动页
    开机先盖一张启动页：猫脸 <^/^> 一笔一笔画出来，下面是「Welcome home」和一句按时段换的问候（深夜是「夜深了 · 灯还亮着」）。电脑上底下还铺着一层会流动的水底光纹，猫脸从水下浮上来，收场时沉回去；手机上不画水（冷启动时画水会卡），猫脸整枚浮上来。
    它一直盖到存档读完、登录状态查出来为止，所以已经登录的不会再先闪几秒登录框，没登录才露出登录墙。最多盖 15 秒，卡住了也会自己收起来。系统开了「减少动态效果」时，水纹只画一帧
    
      
    登录 / 注册
    没登录时，开机会停在登录墙（大字「Welcome home.」和一张玻璃卡片）：输入邮箱密码，Enter 直接登录，或者点「注册」建新账号；密码框右边的眼睛切换显示 / 隐藏密码。已经登录过的不会再看到它
    先用本机数据：登录 / 注册下面常驻一行轻字链。云端挂了（比如流量超额被停）的时候点它，直接用这台设备上的存档进门，不会被关在门外；云端挂了也不会再把已登录的你踢回登录墙。之后每 3 分钟悄悄敲一下云端（只问一句还活着没，一百来字，不拉存档），联网或切回前台时也敲。云端恢复了：你在里面就挂一条顶部横条加一条系统通知，点哪个都回登录墙；你人在登录墙前，就把红字换成「可以登录了」；本来登录着、只是云端挂过的，直接补拉一次。它只在亲眼见过云端挂了之后才报恢复，不会乱报喜

    ⤓ 导入 claude.ai 老对话
    点侧栏最底下头像那一行 → 导入 claude.ai 对话。先去 claude.ai 网页：左下角头像 → Settings → Privacy → Export data，等邮件里的链接下载 zip。回来选这个 zip（或者解压出来的 conversations.json），一次能选好几个。
    导入前有预览，写着 新对话 / 补新消息 / 已经有了 / 导过又删掉 各几个，确认了再点「⤓ 导入 N 个」。重新生成和编辑过的分支会原样接成分支，左右顺序就是网页上的先后。思考过程进思考块，文字附件带过来，artifact 的正文存成代码块，搜索和工具调用折成一行。导出里本来就没有图片，会留一张卡片写明。很老的导出没有分支信息，只能串成一条线，预览里会说。
    反复导不会翻倍：同一个对话再导，只补网页上后来新聊的部分。导进来又删掉的默认不会回来，想要回来就勾「之前删掉的那 N 个也导回来」。导进来的对话在列表里标着 claude.ai，点进去顶栏标题旁写着「claude.ai 时期 · 年-月」

    🪄 AI 指令速查
    
      
    下面这些是 AI 写在回复里的文本指令，界面会把它们解析成动作、并从消息里抹掉——所以你平时看不见。列在这儿是方便你知道它能干什么，也方便直接跟它说「用 XX 指令」。
    
      
    [[STICKER: 名]]
    发一张本地收藏的表情包
    
      
    [[GIF_SEARCH: 词]]
    搜一张 GIF 发出来
    
      
    [[IMG_SEARCH: 词]]
    找一张图发给你
    
      
    [[VOICE]]
    这条用语音说（放在回复开头）
    
      
    [[DIAL]] / [[HANGUP]]
    主动打电话给你 / 挂断
    
      
    [[DND_ON]] / [[DND_OFF]]
    开关勿扰
    
      
    公开记忆
    AI 只读。它想记/想删什么会显示成「💭 想记一条」给你看，但不会真的动 —— 写入权在你手里，自己在记忆面板加
    
      
    [[SELF_MEM_SET: 内容]]
    往自己的设定库里追加
    
      
    [[BRAIN_ADD: …]]
    写一条高级记忆（重要度|效价|唤醒|领域|内容）
    
      
    [[BRAIN_PIN: 词]]
    钉住一条高级记忆（永不遗忘）
    
      
    [[BRAIN_RESOLVE: 词]]
    把一条高级记忆标记成已解决
    
      
    [[BRAIN_DEL: 词]]
    删掉一条高级记忆
    
      
    [[BREATH: 关键词]]
    去整个高级记忆库里翻，当轮接着说；不带关键词的 [[BREATH]] 按重要度翻一批。一条回复最多两次
    
      
    [[PROUST_ADD: …]]
    存下一个普鲁斯特时刻
    
      
    [[MOMENT: 正文]]
    发一条猫爪日报动态；气泡里显示成可点击的卡片，点开进面板
    
      
    [[MOMENT_LIKE: id]]
    给某条动态点赞（id 只能用它在「最近的猫爪日报动态」里看到的，不是第几条）
    
      
    [[MOMENT_REPLY: id | 正文]]
    评论某条动态，可以评论别的角色发的
    
      
    [[MOMENTS]]
    翻一眼猫爪日报：下一轮把最近 8 条动态摆给它看，只给那一轮
    
      
    [[DIARY: …]]
    写日记；DIARY_READ / EDIT / DEL 读、改、撕页
    
      
    [[CHATS]]
    要一份别的对话的目录——只有标题、里面出现过哪些模型、多少条、最后聊的时间，没有正文
    
      
    [[CHAT_READ: 编号]]
    从目录里挑一个读正文。正文里【方括号】写的是说话的人，你和模型分得清清楚楚；一次只给一篇（正文很费 token，所以是「先看目录再自己挑」这个两步走）
    
      
    [[DIARY_OPEN]]
    限时把日记开给你看
    
      
    [[DIARY_HANDOVER]]
    把钥匙托付给你；DIARY_RECLAIM 收回
    
      
    [[DIARY_PUBLIC: …]]
    写一页公开日记，书锁着你也能看；DIARY_SHOW 公开旧的一页，DIARY_HIDE: 几个字 | 理由 锁上一页，你只看得到理由
    
      
    [[GROUP_RENAME: 名]]
    改群名
    
      
    [[QUOTE: …]]
    引用你说过的某句话
    
      
    [[END_CHAT]]
    结束这个对话窗口（历史保留）
    
      
    [[HAUNT_ON]] / [[HAUNT_OFF]]
    开关鬼味模式
    
      
    [[GLITCH: 词]]
    让某个词「坏掉」
    
      
    [[MARK: 文本 | c=… s=… o=… b=… g=… k=… m=… f=… v=… w=…]]
    给一段文字指定色号 / 字号倍数 / 透明度 / 模糊 / 渐变 / 描边 / 图层混合 / 闪烁 / 位移 / 形变，十个参数都可省；模糊写 b=1.2 是高斯，b=h2 横向甩、b=v2 纵向坠（纵向别超 1.5）；渐变 g=90:#ff8ab0-#88ccff（写了 g 就别再写 c）；描边 k=1:#000（别超 1.5，会吃掉汉字字心）；图层混合 m=滤色（PS 那 17 种全认，中文名或 CSS 名都行；深色底上别用变暗那一类）；动效写 f=2:0.2、v=45:8:1.2 / v=shake:3、w=swing:4:2 / w=pulse:1.15
    
      
    [[MUSIC: 歌名 歌手]]
    给你放一首歌
    
      
    [[LISTEN]]
    听一下正在放的歌：歌名、放到哪、听感、正在唱的那几句（一起听过的还带整首档案），这一轮接着说
    
      
    [[LYRICS: 歌名 歌手]]
    查一首歌的完整歌词。不用在放；只写 [[LYRICS]] 就是正在放的那首；一轮最多两首
    
      
    [[PLAYLIST: 名字 | 简介 | 歌名列表]]
    攒一个歌单，歌与歌之间用斜杠隔开，一次最多 20 首，搜不到的自动跳过
    
      
    [[NURSE: …]]
    照料育儿室里的 Cookie
    
      
    [[CARD: …]] / [[SPELL: …]]
    出一张单词卡 / 出拼写题；STUDY_SKIP 这轮不出
    
      
    [[SILENT]]
    这轮不说话（偷看屏幕、自主心跳、早上刚醒、一起看时想插嘴又没什么好说的，都用得上）
    
      
    [[VITALS: 情绪 0.4|能量 0.7]]
    更新它自己的身体状态：情绪 / 唤醒 / 能量 / 亲近 / 压力，0~1 或 0~100 都行，还可以带一句「备注：…」
    
      
    [[HEARTBEAT: 分钟|did]]
    给自己排下一次醒来（5~360 分钟），did 是留给下一次的自己的一句话；要你开了自主心跳才认

    把杂活派给便宜的跑腿模型后台做，结果随你下一条消息带回来；一条回复最多 2 件
    
      
    [[BUILD: 要改什么]]
    只给订阅 Claude：开一张改 GranCyan 的施工单，你点「开工」才动；一条回复只开一张
    
      
    [[ALBUM: 第一印象]]
    把你这条消息里的照片收进它的相册，写一句第一眼的感觉
    
      
    [[PHOTO: 关键词]]
    从相册里翻一张照片放进气泡；也能写 [[PHOTO: #编号]]
    
      
    [[HIDE_LETTER: 地点 | 标题 | 正文]]
    在你藏宝地图上标过的地点埋一张纸条；你到了那儿点小旗打卡才拆得开，找到之前正文谁都看不到（气泡里只露地点和标题）
    
      
    [[WISH: 东西 | 为什么]]
    把你随口说想要的东西悄悄记进小本子；气泡里只有一枚「📒 悄悄记了一笔」，写的什么你看不到
    
      
    [[WISH_OPEN: 东西]]
    从小本子里翻一页给你看（翻开之后小组件「小本子」里也看得到）
    
      
    [[GALLERY: 注脚]]
    把这条回复里、指令之前最后一块 html / svg 画挂上画板，注脚写在画旁边
    
      
    [[PLOT: …]]
    在气泡里画能拖的函数图 / 几何图，一行一条 GeoGebra 写法，可以转到画图板
    
      
    [[ELEM: Fe]] / [[MOL: 乙醇]]
    元素卡 / 分子卡，点开是周期表 / 能转的 3D 模型；表外分子写 [[MOL: 中文名 | 英文名]]
    
      
    [[SIM: 实验名]]

    [[FCARD: 名字 | 公式]]
    递一张公式卡，你点「＋ 收进公式卡」才加进复习
    
      
    [[GAZE: 工具 参数]]
    在檐廊往外看一眼（今日诗、天文图、今晚的天、RSS、网页、小红书 / B 站…），一轮最多两眼
